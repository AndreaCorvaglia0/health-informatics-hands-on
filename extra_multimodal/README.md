# Extra module: multimodal fusion

An optional module, separate from the course. It is for the students who have finished the project, the
nodules (notebook 04) and want one more topic: models that use an image **and** clinical data together.

| File | What it is |
|---|---|
| `multimodal_fusion.ipynb` | the notebook, 10 steps, about 2 hours, CPU is enough |
| `handbook.pdf` | the theory you need for the notebook, 7 pages, in the same order |
| `solutions/multimodal_fusion.ipynb` | the notebook completed (teachers) |

It runs on Kaggle like the other notebooks, with the same dataset (`luna16-lung-slices`, folder `nodules`).
Internet must be on: STEP 8 downloads a pretrained network.

## What is inside

One nodule per patient (601 patients). The question: does a model that sees both the image and the clinical
data predict "alive after one year" better than a model that sees only one?

| Step | Topic |
|---|---|
| 1-3 | the patients, the clinical table, training and test patients |
| 4 | a model on the clinical data only |
| 5 | measurements from the mask (the idea of radiomics) and a model on them |
| 6-7 | early fusion and late fusion |
| 8 | embeddings from a pretrained network |
| 9 | intermediate fusion: a small network with two branches |
| 10 | compare the models, then see how the data were generated |

**The clinical data and the survival are invented.** The images are real. Age, smoking history, performance
status and the outcome are generated by a formula inside the notebook, with a fixed seed. Nothing in this
module has a medical meaning: it teaches the method.

## Results of the solution (test AUC, one split, CPU, about one minute)

| Model | AUC |
|---|---|
| clinical data only | 0.69 |
| image measurements only | 0.77 |
| early fusion | 0.85 |
| late fusion | 0.84 |
| embeddings only | 0.72 |
| early fusion with embeddings | 0.80 |
| intermediate fusion | 0.69 |

The intermediate fusion network is no better than the clinical data alone: 420 training patients are too few to
learn the image branch from scratch. The notebook says so. It is a useful result to discuss.
